# 医院门诊挂号缴费系统 - 前端

## 项目简介

本项目是医院门诊挂号缴费系统的前端实现，采用 **Vue 2.6 + Element UI** 的CDN引入方式开发，无需Node.js构建环境，浏览器直接打开即可运行。

## 技术栈

- **框架**：Vue 2.6.14（CDN引入）
- **UI组件库**：Element UI（CDN引入）
- **HTTP请求**：Axios（CDN引入）
- **样式**：原生CSS3
- **认证方式**：JWT Token（localStorage存储）

## 项目结构

```
hospital-frontend/
├── login.html              # 登录页面
├── index.html              # 主页面（包含所有功能模块）
├── css/
│   └── style.css           # 全局样式文件
├── js/
│   └── api.js              # API请求封装（Axios）
└── README.md               # 项目说明文档
```

## 功能模块

### 患者端
- 工作台（数据统计概览）
- 预约挂号（四步向导：选科室→选医生→选时间→确认）
- 我的挂号记录（查看、取消）
- 我的处方
- 我的缴费

### 医生端
- 工作台（今日挂号统计）
- 挂号队列（叫号、完成看诊）
- 叫号大屏（当前叫号+等待队列）

### 收费员端
- 工作台（缴费统计）
- 缴费管理（查询、现场缴费）
- 退款管理

### 管理员端
- 工作台（系统数据概览）
- 用户管理
- 科室管理

## 快速开始

### 前置条件
1. 后端服务已启动（http://localhost:8080/api）
2. MySQL数据库已初始化
3. 现代浏览器（Chrome、Edge、Firefox等）

### 启动步骤
1. 直接双击打开 `login.html` 文件
2. 或在浏览器地址栏输入：`file:///项目路径/hospital-frontend/login.html`
3. 使用测试账号登录

## 后端接口

- **接口文档**：http://localhost:8080/api/doc.html
- **基础路径**：http://localhost:8080/api
- **接口数量**：30+个RESTful API

## 核心特性

1. **前后端分离**：前端通过Axios调用后端RESTful API
2. **JWT认证**：登录后获取Token，后续请求自动携带
3. **角色权限控制**：根据用户角色动态显示菜单和功能
4. **响应式布局**：适配不同屏幕尺寸
5. **无需构建**：CDN引入依赖，浏览器直接运行

## 注意事项

1. 前端页面通过 `file://` 协议打开时，部分浏览器可能限制跨域请求。如遇跨域问题，可使用本地HTTP服务器：
   ```bash
   # Python 3
   python -m http.server 8081
   # 然后访问 http://localhost:8081/login.html
   ```

2. 后端已配置CORS跨域支持，正常情况下可直接访问。

3. Token有效期为24小时，过期后需重新登录。
